Pimpinan Program Studi

Kepala Program Studi

Nama Kaprodi, S.Kom., M.Kom.

Memimpin arah akademik dan pengembangan kurikulum Program Studi Teknik Informatika, serta bertanggung jawab atas mutu penyelenggaraan pendidikan dan kerja sama institusi.

Wakil Kepala Program Studi

Nama Wakaprodi, S.Kom., M.Kom.

Membantu koordinasi kegiatan akademik dan kemahasiswaan, serta mendampingi pelaksanaan program kerja sama dan pengembangan dosen.

Sekretaris Program Studi

Nama Sekretaris, S.Kom., M.T.

Mengelola administrasi akademik, dokumentasi kurikulum, serta mendukung kelancaran proses perkuliahan dan evaluasi program studi.

Koordinator Laboratorium

Nama Koordinator, S.Kom.

Bertanggung jawab atas pengelolaan dan perawatan fasilitas laboratorium, serta mendukung kegiatan praktikum mahasiswa.

Koordinator Kemahasiswaan

Nama Koordinator, S.Kom., M.Kom.

Mendampingi kegiatan organisasi dan pengembangan minat-bakat mahasiswa, serta menjadi penghubung antara mahasiswa dan program studi.
